# BlockCrafters – Minecraft Building Studio

A responsive five-page website for a fictional Minecraft building studio. This is a client-side student project built with HTML, CSS, Bootstrap, JavaScript, localStorage, a public API, and jQuery.

## Pages

- `index.html` – introduction, dashboard, and Minecraft Java server status checker.
- `about.html` – studio information, process, and jQuery FAQ accordion.
- `services.html` – dynamically rendered service packages and price estimator.
- `gallery.html` – searchable, filterable, sortable build gallery with CRUD.
- `contact.html` – custom client-side form validation.

## Final-stage features

1. API integration using the public mcstatus.io API.
2. Object-oriented JavaScript using a Build class.
3. localStorage for saving builds and theme preferences.
4. CRUD: create, read, update, and delete gallery records.
5. Advanced search, filtering, and sorting.
6. Dashboard and category statistics.
7. Custom form validation.
8. jQuery FAQ accordion and hover interactions.

## Run locally

1. Open the project folder in VS Code.
2. Open `index.html` using Live Server.
3. Internet access is required for Bootstrap, jQuery, and the mcstatus.io API.

## Important notes

- Contact form submissions are validated but are not sent to a server.
- Build data and theme settings are saved only in the current browser.
- Replace group member details with your real group information.
